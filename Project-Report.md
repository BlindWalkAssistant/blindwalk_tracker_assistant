# Blind Assist System

This project is developed to help visually impaired people using real-time object detection through camera input.

The system detects nearby objects such as:
- Chair
- Table
- Book
- Road signs

and provides voice feedback to the user.

## Technologies Used
- Python
- YOLO
- OpenCV
- TensorFlow

## Hardware Research
- NVIDIA Jetson Orin Nano
- Intel RealSense D435
