# AI-Based Blind Assist System

This project is designed to assist visually impaired people using AI-based object detection and voice feedback.

## Technologies Used
- Python
- OpenCV
- TensorFlow Lite
- Mobile Camera Integration
- Text-to-Speech

## Features
- Real-time object detection
- Voice output for detected objects
- Mobile camera support using IP Webcam
- Lightweight assistive system
